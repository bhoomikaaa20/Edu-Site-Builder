AI Technologies

The engines behind modern AI

Almost every AI product you use is built on a small set of techniques. Here are the three you'll hear about most: Machine Learning, Deep Learning, and Natural Language Processing.

The map of AI techniques

These technologies aren't separate worlds — they nest inside each other. The diagram below uses a nested list to make that hierarchy explicit.

  • Artificial Intelligence — the broad field
    • Machine Learning (ML) — systems that learn from data
      • Supervised Learning — learns from labeled examples
        • Classification (spam vs. not spam)
        • Regression (predicting house prices)
      • Unsupervised Learning — finds patterns without labels
        • Clustering (grouping similar customers)
        • Dimensionality reduction
      • Reinforcement Learning — learns through trial and reward
        • Game-playing agents
        • Robotics control
    • Deep Learning (DL) — ML using deep neural networks
      • Convolutional Neural Networks (vision)
      • Recurrent Neural Networks (sequences)
      • Transformers (language, vision, audio)
    • Natural Language Processing (NLP) — AI for human language
      • Text classification & sentiment analysis
      • Machine translation
      • Question answering & chatbots
      • Large Language Models (LLMs)

Quick definitions

Machine Learning

Machine Learning is the practice of teaching a computer by showing it examples instead of writing explicit rules. Give it 10,000 photos tagged "cat" or "dog" and it will learn to tag new photos on its own.

Deep Learning

Deep Learning is a more powerful flavor of Machine Learning that uses many-layered neural networks. It's the technology behind today's image recognition, speech recognition, and large language models.

Natural Language Processing

NLP is the area of AI that deals with human language — reading it, writing it, translating it, summarizing it, and answering questions about it. Modern chatbots are NLP systems built on Deep Learning.
