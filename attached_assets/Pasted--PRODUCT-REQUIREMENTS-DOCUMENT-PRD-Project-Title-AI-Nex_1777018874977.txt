📄 PRODUCT REQUIREMENTS DOCUMENT (PRD)
🧾 Project Title

AI Nexus – Educational Website for Artificial Intelligence

🎯 1. Purpose

The purpose of this project is to design and develop a professional, multi-page educational website that explains Artificial Intelligence (AI) concepts in a clear, simple, and engaging manner.
The website should demonstrate strong front-end development skills using HTML, CSS, and JavaScript only.

👥 2. Target Audience
Students learning AI
Beginners (non-technical users)
Researchers (basic overview)
General tech enthusiasts
🌐 3. Scope

The website will:

Provide structured AI learning content
Include interactive UI elements
Be responsive across devices
Use only HTML, CSS, JavaScript (no frameworks)
